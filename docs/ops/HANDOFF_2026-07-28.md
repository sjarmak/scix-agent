## Findings filed during execution — read before touching related code

Ranked by what will hurt soonest.

**P0 · `tests/test_schema.py` connects to production.** Line 10 reads
`SCIX_DSN`, not `SCIX_TEST_DSN`, defaulting to `dbname=scix`. The module opens a
connection to the production database *even when the documented guard is
exported*, then runs `INSERT INTO paper_embeddings`. Writes are savepoint-wrapped
and rolled back at module teardown, so nothing persists — but the suite takes
locks on prod tables, and killing pytest mid-run strands an idle-in-transaction
session against prod. It fails closed today only because ADR-015 dropped that
table. `CLAUDE.md` says the guard is `SCIX_TEST_DSN`; this file predates or
ignores it. **Check whether any other test module does the same before assuming
it is the only one.**

**P1 · The unembedded query full-scans the corpus every run.** `EXPLAIN` shows
`Parallel Seq Scan on papers` (width 351, so it reads every abstract including
TOAST) hash-anti-joined against a full scan of `indus_qdrant_synced`, cost ~10.1 M.
Measured **530 s before the first row on a cold cache**; of the 540 s full drain,
~530 s was this query and **~10 s was actual GPU work**. Warm-cache it drops to
~28 s, which is why the manual `daily_sync` run looked fine. Introduced by
`de0e006` — correct, but it does not scale. Likely fix: bound the nightly job by
ingest recency against a last-run watermark, keeping the unbounded form behind a
`--full` flag for backfills.

**P1 · The health gate has no alert sink.** It runs from exactly one place, the
end of `daily_sync.sh`, whose cron line has no `MAILTO` and appends to the log
that went unread for 12 days. If the script dies *before* reaching the gate —
precisely the failure mode it exists to catch — nothing fires at all. The
staleness sub-check also cannot fire in its only context, since the run that just
wrote the status file is always fresh. `logs/daily_sync_status.json` makes the
state queryable out-of-band, which is the mechanism an independent check needs.
Proposed two-line fix (operator, it is a production scheduling change):

```cron
MAILTO=stephanie.jarmak@cfa.harvard.edu
45 7 * * * cd /home/ds/projects/scix_experiments && .venv/bin/python scripts/check_pipeline_health.py --allow-prod
```

**P2 · A test mutates a tracked file.**
`tests/test_search_within_paper_rerank.py:348` writes into
`results/within_paper_rerank_eval.md` on every run, so "clean tree" and "green
suite" cannot both hold. It corrupted a commit during this goal: a concurrent
suite run rewrote the file between `git add` and `git commit`, recording 4096 ms
(CPU-only cross-encoder under load) instead of the real 8.4 ms.

**P2 · Dead outbox coverage.** `tests/test_qdrant_outbox_sync.py` exercises the

**P2 · `scix_experiments-zng` — rebase the dbl.8 entity work.** PR #6 was closed

## Operational notes that will save you an hour

- **`QDRANT_URL` is not in your shell.** `daily_sync.sh` sources `.env`; a manual
  run does not. Always `set -a; source .env; set +a` before running
  `scripts/embed.py`, or it dies with `QDRANT_URL is unset`. `.env` carries the
  comment *"Added 2026-07-14 (bead zyuc): daily_sync embed step had failed 8
  nights with 'QDRANT_URL is unset'"* — this pipeline has now failed silently
  three separate times, for three different reasons. **Smoke-test with `--limit
  100` before any full run.**
- **Cron is `15 6 * * *` local = 10:15 UTC.** Log stamps are UTC; the host is
  UTC-4. Do not start a long GPU job that will overlap it.
- **The pre-push hook is real.** `.git/hooks/pre-push` symlinks to
  `~/gas-city/hooks/pre-push` and runs gitleaks against `$ROOT/.gitleaks.toml`.
  That file now exists (bead `hw3p`, closed). Do not reach for `--no-verify`; if
  it fires, read the finding.
- **Wrap heavy work in `scix-batch`.** The host also runs the gascity supervisor,
  and `user@1000.service` has `ManagedOOMMemoryPressure=kill` at 50%.
- **Branch inventory baseline:** `docs/ops/branch_inventory_2026-07-27.txt` (30
  refs, pre-prune) and `..._2026-07-28_postprune.txt`. All worktrees were removed;
  every branch ref was kept. Re-check out any branch on demand.
